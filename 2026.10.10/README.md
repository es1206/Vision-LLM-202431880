# Section Project - 학생 성적 분석

## 프로젝트 설명
5명의 학생 정보와 국어, 수학, 과학 성적을 이용하여 Python과 NumPy로 학생 명단, 전체 성적, 85점 이상 개수, 학생별 평균, 최고 평균 학생, 단일 과목 최고 점수를 분석합니다.

## 파일 구성
- `section_project.py`: 데이터와 6개 분석 항목이 포함된 독립 실행 파일

## 실행 환경 및 방법
- Python 3
- 의존성: NumPy

```bash
python -m pip install numpy
python section_project.py
```

환경에 따라 `python` 대신 `python3` 명령을 사용합니다.

## 구현 내용
1. 리스트 컴프리헨션과 `split()`으로 이름 추출
2. `flatten()`으로 2차원 성적 배열을 1차원으로 변환
3. 조건 비교와 `np.sum()`으로 85점 이상 개수 계산
4. `np.mean(axis=1)`으로 학생별 평균 계산
5. `np.argmax()`로 평균 최고 학생 선택
6. `np.argmax()`, 나머지(`%`), 몫(`//`) 연산으로 최고 점수의 과목과 학생 확인

## 참고 사항
- 문제에 제공된 데이터를 사용했습니다.
- 평균 점수는 소수점 둘째 자리까지 표시합니다.
- 최고 점수가 여러 개라면 `np.argmax()`가 반환하는 첫 번째 위치를 기준으로 표시합니다.
