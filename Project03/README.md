## 1. 프로젝트 개요

본 프로젝트는 YOLO 객체 탐지, Gemma 언어 모델, Piper TTS를 활용하여 휴대폰을 놓거나 치우는 행동만으로 집중 시간을 관리하는 AI 학습 보조 프로그램이다.

책상 위를 촬영하는 카메라에서 휴대폰이 감지되면 집중 타이머가 시작되고, 휴대폰이 화면에서 사라지면 일시정지된다. 상태가 변경될 때 Gemma가 피드백 문장을 생성하고 Piper TTS가 스피커로 안내한다.

주요 구현 내용은 다음과 같다.

1. **YOLO 기반 휴대폰 탐지**
   - OpenCV를 이용한 Jetson 카메라 입력
   - YOLO11 모델의 `cell phone` 클래스 탐지
   - 3프레임 연속 감지 여부에 따른 상태 전환

2. **집중 타이머**
   - 휴대폰 감지 시 타이머 시작 또는 재개
   - 휴대폰 미감지 시 타이머 일시정지
   - 누적 집중 시간 측정

3. **Gemma 기반 AI 피드백**
   - 집중 시작 및 일시정지 이벤트 분석
   - 집중 시간에 따른 한국어 안내 문장 생성

4. **Piper TTS 음성 안내**
   - Gemma가 생성한 문장을 음성으로 변환
   - 스피커를 통한 집중 상태 안내

5. **집중 기록 저장**
   - 현재 집중 상태 및 시간 화면 표시
   - CSV 파일에 누적 집중 시간 기록

## 4. 구현 내용

### 4-1. YOLO 객체 탐지

`YOLO()`를 이용하여 모델을 불러오고 `predict()`로 휴대폰을 탐지한다.

```python
result = yolo.predict(
    source=frame,
    conf=0.4,
    iou=0.5,
    classes=[67],
    verbose=False
)[0]
```

탐지된 Bounding Box가 하나 이상이면 휴대폰이 보이는 상태로 처리한다.

`result.plot()`을 이용해 탐지 결과를 카메라 화면에 표시한다.

### 4-2. 집중 타이머

`focused` 변수를 이용하여 현재 집중 상태를 관리한다.

`present_frames`와 `absent_frames`로 연속 탐지 여부를 확인한다.

- 휴대폰 3프레임 연속 감지: 집중 시작
- 휴대폰 3프레임 연속 미감지: 일시정지
- 다시 감지: 누적 시간부터 재개

시간 측정에는 `time.monotonic()`을 사용한다.

### 4-3. Gemma 피드백 생성

`feedback()` 함수는 집중 이벤트와 누적 집중 시간을 Gemma에 전달한다.

Gemma는 전달된 정보를 기반으로 짧고 친절한 한국어 안내 문장을 생성한다.

```text
이벤트: 집중 시작
누적 집중 시간: 0초

AI 응답 예시:
"휴대폰을 내려놓으셨네요. 집중을 시작해 볼까요?"
```

```text
이벤트: 집중 일시정지
누적 집중 시간: 300초

AI 응답 예시:
"현재까지 5분 동안 집중하셨습니다. 다시 시작할 준비가 되면 휴대폰을 내려놓아 주세요."
```

Gemma는 실제 사용자의 집중 여부를 판단하지 않고 카메라 감지 상태를 기준으로 피드백을 생성한다.

### 4-4. Piper TTS 음성 출력

`speak()` 함수는 Gemma의 응답을 음성으로 변환한다.

Piper 모델을 이용하여 WAV 파일을 생성하고 `aplay`로 재생한다.

음성은 집중 시작 또는 일시정지 이벤트가 발생했을 때 출력된다.

### 4-5. 집중 시간 기록

`save_log()` 함수는 집중 시간을 CSV 파일에 저장한다.

```text
기록 시각, 누적 집중 시간(초)
2026-11-08 10:15:00, 120.5
```

위 기록은 저장 형식을 설명하기 위한 예시이다.

프로그램은 일시정지 및 종료 시 누적 시간을 저장하므로 각 기록을 독립된 집중 시간으로 합산하지 않는다.

## 5. 창의성 및 차별성

### 5-1. 휴대폰을 물리적인 타이머 스위치로 활용

기존 집중 타이머는 사용자가 시작과 중지 버튼을 직접 조작해야 한다.

본 프로젝트는 휴대폰을 카메라 영역에 놓거나 치우는 행동으로 타이머를 제어한다.

이를 통해 별도의 버튼 조작 없이 집중 시간을 관리하는 비접촉식 인터페이스를 구현하였다.

### 5-2. 객체 탐지를 실제 기능으로 확장

일반적인 YOLO 객체 탐지는 물체의 종류와 위치를 표시하는 데 중점을 둔다.

본 프로젝트는 휴대폰 탐지 결과를 집중 시작과 일시정지 이벤트로 연결하였다.

즉, 단순히 휴대폰을 인식하는 것이 아니라 인식 결과를 활용하여 실제 타이머 기능을 실행한다.

### 5-3. 생성형 AI 기반 맞춤형 음성 피드백

기존 타이머는 정해진 알림음이나 문구를 출력한다.

본 프로젝트는 Gemma가 현재 집중 상태와 누적 시간을 바탕으로 안내 문장을 생성한다.

Piper TTS를 결합하여 사용자가 화면을 확인하지 않아도 집중 상태를 음성으로 알 수 있도록 하였다.

### 5-4. 좁은 카메라 범위를 활용한 실생활 AI

사람 전체나 넓은 공간을 촬영할 필요 없이 책상 위 휴대폰 하나만으로 동작하도록 설계하였다.

이를 통해 Jetson과 웹캠을 이용한 간단한 환경에서도 실생활에 활용할 수 있는 AI 시스템을 구현하고자 하였다.

### 5-5. 집중 시간 자동 기록

휴대폰 감지 여부에 따라 집중 시간을 측정하고 CSV 파일에 저장한다.

단순한 객체 인식과 음성 안내에서 끝나지 않고, 측정 결과를 기록할 수 있다는 점에서 차별성이 있다.

## 6. 확장성 및 발전 가능성

### 6-1. 사용자 행동 분석을 통한 집중 시간 측정 정확도 개선

현재는 YOLO를 활용하여 책상 위 휴대폰의 존재 여부를 판단하고, 휴대폰이 감지되면 집중 시간을 측정하는 방식으로 구현하였다.

그러나 휴대폰이 책상 위에 있더라도 사용자가 직접 휴대폰을 조작할 수 있기 때문에, 객체 탐지만으로 실제 학습 집중 여부를 정확하게 판단하기에는 한계가 있다.

향후에는 YOLO 기반 휴대폰 객체 탐지에 사용자의 손 위치와 행동 분석을 결합하여 집중 상태를 보다 정확하게 판단하도록 개선할 계획이다.

예를 들어 MediaPipe 또는 YOLO Pose를 활용하여 손과 휴대폰의 위치 관계, 휴대폰을 집어 드는 행동 등을 분석하고, 휴대폰 사용이 의심되는 상황에서는 집중 타이머를 일시정지하도록 확장할 수 있다.

이를 통해 단순히 휴대폰이 책상 위에 있는 시간을 측정하는 방식에서 나아가, 사용자의 행동을 함께 고려하는 집중 관리 시스템으로 발전시키고자 한다.

단, 휴대폰 조작 여부만으로 실제 학습 집중도를 완전히 판단할 수는 없으므로, 행동 분석 결과를 집중 상태를 추정하는 보조 지표로 활용할 예정이다.

### 6-2. CSV 기록을 활용한 집중 시간 시각화

현재는 `focus_log.csv` 파일에 측정 시각과 누적 집중 시간을 저장하고 있다.

그러나 사용자가 집중 기록을 확인하려면 별도의 CSV 파일을 열어야 하므로, 프로그램 실행 중 자신의 학습 현황을 직관적으로 확인하기 어렵다는 한계가 있다.

향후에는 저장된 CSV 데이터를 활용하여 프로그램 실행 화면 상단에 집중 기록을 표시하는 대시보드 기능을 추가할 계획이다.

주요 개선 기능은 다음과 같다.

- 현재 집중 상태(FOCUS / PAUSED) 표시
- 현재 세션의 누적 집중 시간 표시
- 오늘의 총 집중 시간 및 목표 달성률 표시
- 집중 시작 및 일시정지 횟수 표시
- 일별·주별 집중 시간 통계 시각화

특히 OpenCV의 화면 출력 기능을 활용하여 카메라 영상 상단에 배너 형태로 집중 시간과 기록을 표시함으로써, 별도의 파일을 열지 않아도 학습 현황을 확인할 수 있도록 개선하고자 한다.

또한 기존 CSV 기록을 날짜별·세션별로 구분하여 저장하도록 확장함으로써 일별 총 집중 시간과 학습 패턴을 보다 정확하게 분석할 계획이다.

### 6-3. Gemma 기반 개인 맞춤형 피드백 확장

현재는 집중 시작과 일시정지 이벤트 및 누적 집중 시간을 Gemma에 전달하여 짧은 한국어 피드백을 생성한다.

향후에는 CSV에 저장된 집중 기록을 Gemma의 입력 정보로 추가하여 사용자의 학습 패턴에 맞는 개인화된 피드백을 제공하도록 확장할 수 있다.

예를 들어 이전보다 집중 시간이 증가한 경우에는 격려 메시지를 제공하고, 집중 중단이 반복되는 경우에는 짧은 휴식을 제안하는 방식이다.

이를 통해 단순한 상태 안내를 넘어 사용자의 학습 습관 개선을 지원하는 AI 학습 코치로 발전시키고자 한다.

### 6-4. 탐지 안정성 및 실시간 처리 개선

현재는 휴대폰이 3프레임 연속 감지되거나 감지되지 않을 때 집중 상태가 변경된다.

그러나 조명 변화, 물체 가림, 카메라 각도 등에 따라 일시적인 탐지 오류가 발생할 수 있다.

향후에는 프레임 개수뿐만 아니라 일정 시간 동안의 탐지 결과를 종합하여 상태를 판단하는 방식으로 개선할 계획이다.

또한 현재는 Gemma의 응답 생성과 Piper TTS 음성 출력이 완료될 때까지 카메라 처리가 일시적으로 중단될 수 있다.

이를 개선하기 위해 객체 탐지 및 타이머 처리와 음성 피드백 기능을 비동기적으로 실행하여 실시간 영상 처리의 연속성을 높이고자 한다.

### 6-5. 학습 목표 및 휴식 관리 기능 확장

현재는 휴대폰 감지 여부를 기준으로 집중 시간을 측정하고 누적 기록을 저장한다.

향후에는 사용자가 하루 목표 집중 시간을 설정하고, 목표 달성 여부에 따라 음성 피드백을 제공하는 기능으로 확장할 수 있다.

또한 뽀모도로 학습법을 적용하여 일정 시간 집중한 후 휴식을 안내하고, 집중 시간과 휴식 시간을 반복적으로 관리할 수 있도록 개선할 계획이다.

이를 통해 단순한 집중 시간 측정 프로그램에서 사용자의 학습 계획과 습관 형성을 지원하는 종합적인 학습 관리 서비스로 발전시키고자 한다.

## 7. 기타 참고 사항

### 7-1. 코드 관련 추가 설명

- `speak()`: Piper TTS 음성 생성 및 재생
- `feedback()`: Gemma를 이용한 집중 상태별 피드백 생성
- `save_log()`: 집중 시간 CSV 기록
- `main()`: 모델 로딩, 카메라 입력, 객체 탐지 및 타이머 관리
- `CONFIDENCE = 0.4`: YOLO 탐지 신뢰도 임계값
- `STABLE_FRAMES = 3`: 집중 상태 전환을 위한 연속 프레임 수
- `classes=[67]`: 휴대폰 객체만 탐지
- `q`: 프로그램 종료

### 7-2. 실행 환경 관련 참고 사항

- 모델 경로는 `main.py` 상단에 지정되어 있다.
- Jetson 환경에 따라 모델 및 Python 가상환경 경로를 수정해야 할 수 있다.
- TensorRT 엔진은 사용 중인 Jetson 환경과 호환되어야 한다.
- Gemma 응답 생성 및 TTS 실행 중 카메라 화면이 잠시 멈출 수 있다.
- 휴대폰이 카메라에서 가려지거나 탐지되지 않으면 타이머 상태가 변경될 수 있다.
- 집중 시간은 휴대폰이 감지된 상태의 누적 시간이며 실제 학습 몰입도를 측정하지는 않는다.
- 실제 Jetson 카메라와 스피커에서의 실행 여부는 별도로 확인해야 한다.
